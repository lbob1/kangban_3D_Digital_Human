## 别人 pull 后能正常启动吗 —— 能，但账号数据要自己建

- **不会报错**，前提是按 README 装好环境：Python 3.12+、PostgreSQL 15+（带 pgvector 扩展）、复制 `.env.example` 为 `.env` 自填数据库密码和**自己生成**的 JWT_SECRET_KEY
- 数据库是空的——**你的理解正确**：`kangban_dev` 是你本机的库，不在仓库里
- **账号密码不能共用**：你的 admin/护士/家属账号都存在你本机数据库中，别人拿不到。他们需运行 `seed_admin.py` **交互式输入自己的管理员用户名密码**（幂等，仅无 admin 时创建）；护士/家属/医生账号再由他们自己的 admin 登录后台创建，房间/长者数据同理
- 外部依赖全是可选：FunASR/声纹未配置走可见降级、LLM 未配置走模板回复、EdgeTTS 需联网——缺了照样启动

## 启动流程 —— README「快速开始」一节就是完整流程

给别人时的最短路径（README 第 80-112 行原样可照做）：

```powershell
# ① 装依赖
python -m venv .venv; .venv\Scripts\activate; pip install -e ".[dev,infra]"


# ② 配置：复制 .env.example 为 .env，填数据库密码 + 自生成 JWT 密钥
Copy-Item .env.example .env

python -c "import secrets; print(secrets.token_hex(32))"   # 输出填入 JWT_SECRET_KEY


# ③ 起数据库（Docker pgvector）→ 迁移 → 建 admin
alembic upgrade head

python scripts/seed_admin.py


# ④ 启动 + 验活
python -m uvicorn app.main:app --reload

# 浏览器打开 http://127.0.0.1:8000 → 用 seed 的 admin 登录，后台建护士/家属账号
```

跑测试额外需要 README 第 5 步建 `kangban_test` 库，不跑测试可跳过。

## Day7+ 注意事项（2026-11-10 联调实测）

- **启动服务前关闭系统代理**（VPN/Clash 等）：TTS（EdgeTTS）经代理会产生 `SSLCertificateError` 导致合成失败降级——实测 uvicorn 启动终端开着代理（127.0.0.1:3067）即复现，干净进程正常。若忘记关闭，页面会直接显示真实错误详情（TTS 失败自动重试 1 次 + 错误上屏），重启服务即可恢复。
- **媒体曲库为空**：先运行 `uv run python scripts/import_user_media.py`（扫描 `music/`、`yuejv/` 文件夹幂等导入 mp3，需迁移 0016）。用户自备素材仅限本地教学演示，不可分发。
- **媒体播放 404 排查**：`/static` 别名挂载已修复既有 `/static/media/...` 口径；注意 `app/main.py` 中 `/static` 挂载必须位于 `/` 挂载**之前**（`Mount("/")` 前缀通吃，顺序颠倒则别名永不命中）。
