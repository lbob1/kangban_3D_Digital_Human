## 3. 全局升级（一次落地，八页面共享）

### 3.1 动效令牌（`main.css` 的 `:root` 新增，三主题各自覆写颜色类令牌）

```css
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);   /* fluxora 同款统一缓动，全站只有这一条曲线 */
--t-fast: 0.2s;  --t-mid: 0.35s;  --t-slow: 0.6s;
--lift: -6px;                                  /* 微弹抬升量 */
--tilt: 2.5deg;                                /* 倾斜基准角（执行时先做此值给用户过目） */
--ring-speed: 24s;                             /* 装饰环一圈时长（慢速） */
```

### 3.2 卡片微弹（全站统一 hover 语言，selene §3 同款）

- `.card:hover` → `translateY(var(--lift))` + 描边色切换 `var(--hover-border)` + 阴影加深，`transition: transform/background/box-shadow var(--t-mid) var(--ease-out)`；**一次只改 1–2 个属性，反馈明确不抢戏**。
- `:focus-visible` 同款视觉（键盘可达）；`:active` 按压 `scale(0.98)`（触屏主反馈）。
- `@media (hover: none)`：跳过 hover 态，只保留 `:active` 按压——长者平板触屏自动适配。
- **操作区排除**：表格行、表单控件、对话框内的卡片不加微弹（D5 克制边界）。

### 3.3 右上角旋转装饰环（selene 轨道环，纯 CSS）

- 形状：细描边圆环 + 环上一个小圆点（`border` 圆环 + 伪元素内点，或 CSS 多重径向渐变），零图片零 SVG 文件。
- 动画：`rotate(360deg)` 线性循环，`var(--ring-speed)` 一圈（约 24s，肉眼「在动但不吵」）；父卡 hover 时加速到 6s（`animation-duration` 过渡）。
- 颜色：`var(--clay)` 半透明（三主题变量自动适配；夜空黑下最出效果）。
- 尺寸：约 56px，`position: absolute` 卡片右上角，`aria-hidden="true"` 纯装饰。
- **落点（D3）**：登录页角色卡 ×3 + 四个工作台统计卡行；elder 数字人卡用**减速版**（§4.2）。

### 3.4 入场交错动画（fluxora rise stagger）

- `@keyframes rise { from { opacity: 0; transform: translateY(22px); } to { opacity: 1; transform: none; } }`，单卡 `0.6s var(--ease-out) both`。
- 原生 JS（新增 `js/motion.js`，约 60 行）：页面首次加载时，对 `[data-stagger]` 容器内的直接子卡按索引设置 `style.animationDelay = i * 70ms`；**只在 `DOMContentLoaded` 执行一次**，Tab 切换 / 列表重渲染不重播（D6）。
- **红线**：文字内容不单独延迟出现（卡片整体动，卡内文字随卡）；关键信息（登录表单、紧急状态）不加延迟。

### 3.5 全局动效开关（D7，selene「低动效开关」同款）

- 每页左下角固定小胶囊按钮（🎬 图标 + 「动效」字样，半透明，不占布局），点击切换。
- 状态：`localStorage["kb-motion"]`（"on" / "off"）；**未设置时跟随系统 `prefers-reduced-motion`**：系统开了减弱动效 → 默认 off。
- 实现：`html[data-motion="off"]` 下所有新增动画/过渡 `duration: 0.001ms !important`、装饰环静止、入场动画直接终态。CSS 一条规则覆盖，无需逐个改。
- `js/motion.js` 统一挂载（开关 + stagger + 系统偏好监听三合一，全站一份）。

### 3.6 字距标签体系（selene「字距当设计元素」）

- 新增 `.kicker` 工具类：小字号（12–13px）、`letter-spacing: 0.16em`、大写或加宽中文、`var(--clay)` 色——用于各页已有区块小标题（「实时状态」「今日关注」「房间概览」等文案不变，只强化排版层级）。
- 统计卡数字加 `font-variant-numeric: tabular-nums`（等宽数字仪表感，数字变化不跳动）。

### 3.7 兼容性与性能红线（铁律，逐条验收）

1. **只动 `transform` / `opacity` / `box-shadow` / `background-color`**，不触发布局重排；装饰环旋转在独立合成层（`will-change: transform` 只给环）。
2. `backdrop-filter`（毛玻璃）一律包 `@supports`，不支持的旧 WebView 静默退纯色底。
3. 倾斜用 `transform: rotate()`（**不用 clip-path 多边形**，旧 WebView 兼容性更差且无法 hover 回正过渡）。
4. 视频背景逻辑（`login-bg.css` / `login-bg.js`）**只叠加不修改**——已验收代码零改动。
5. 纯静态层改动：不碰后端、不碰接口、不碰 `app/` Python 代码；pytest / ruff 结果零变化。
6. 动效开关 off + `prefers-reduced-motion` 双保险（§3.5）。

### 4.2 elder.html 长者端（D8 同样大胆 + 适老安全网）

**大胆部分**：数字人卡片上倾斜（±2°）+ 右上角装饰环（**减速版 40s 一圈**）+ 数字人卡呼吸感（`scale 1 → 1.02` 循环 4s，极缓）；功能卡片交错入场（首屏一次）。

**适老安全网（不砍效果，加防护）**：

1. 大按钮 `:active` 按压 `scale(0.97)` + 阴影内收——触屏上的主要反馈（平板无 hover）。
2. 装饰环转速减半（40s）、呼吸感幅度极小（2%）、**无任何大幅自动位移循环**（防前庭眩晕）。
3. 关键信息零延迟：健康状态卡、紧急呼叫按钮**不参与入场动画**，打开即见。
4. 动效开关在长者端同样可用（§3.5），家属/护工可帮长者一键关掉。
5. ⚠️ 风险如实告知：触屏设备上倾斜与装饰环收益低于桌面端（无 hover 回正叙事），此为用户知情决策 D8；若实测观感不佳，回退仅删 elder 专属一段 CSS（改动隔离，见 §6 文件结构）。

## 5. 三主题适配（D4：CSS 变量驱动，一次实现三主题自动适配）

| 令牌 | 陶瓷白（默认） | 暖陶雅集 | 夜空黑 |
| --- | --- | --- | --- |
| `--hover-border` | 陶土色 30% 透明 | 暖棕 35% | 米白 25%（hairline 风） |
| `--glow-shadow` | 浅暖灰阴影，无发光 | 暖棕柔光 | **陶土色外发光**（selene 中间卡同款，最出效果） |
| `--ring-color` | `--clay` 40% | `--clay` 45% | `--clay` 60%（暗底下更亮） |
| `--glass-bg` | 白 92% + blur | 米白 92% + blur | 深色 70% + blur |
| 装饰环大小/亮度 | 中卡环稍大 | 同左 | 中卡环最大 + 微光晕 |

- **对比度红线**：所有动效不改变任何文字颜色与背景对比度（动的是卡片的位移/描边/阴影，不是文字）——三主题 WCAG 结论维持 Day2/Day3 既有水准，无需重算。
- 夜空黑天然最接近参考案例的暗色高级感，零额外成本即达「演示主打」效果。

## 8. 验收标准（逐项实测）

| # | 验收项 | 方法 | 通过口径 |

| 1 | 卡片微弹 | 鼠标悬停各页卡片 | `translateY(-6px)` + 描边变色 + 阴影加深，0.35s，全站手感一致 |
