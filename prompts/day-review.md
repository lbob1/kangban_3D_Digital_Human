# day-review · 每日验收报告提示词骨架

> 来源沉淀：Day6~Day9 验收报告惯例（逐项打勾+证据+口径注记）。

```
请依据《Day_plan/DayN_主题.md》§9 验收标准逐项验收 DayN，生成 docs/DayN_验收报告.md：

1. 逐项验收表：| # | 验收项 | 结果✅/❌/注记 | 证据（实测命令+输出数字+commit hash）|，
   不允许出现没有证据支撑的 ✅；
2. 测试基线：开工实测收集例数 vs 收官实测例数（--collect-only 实测，不以历史报告口径为准），
   全量 pytest + ruff 新增违例数 + eval/gate.py exit code；
3. 口径注记节：与主文档/大纲字面的差异逐条如实记录（含未达标项的差距与原因）；
4. 遗留移交节：注记收官项 / 后续可选 / 移交下日，逐条给出依据文件；
5. 不达标项禁止粉饰：如实写「未达标+原因+去向」，验收报告宁可难看不可失真。
```

## 验收报告必含小节

结论预览（一行）→ 逐项验收表 → 测试与门禁基线 → 口径注记 → 遗留移交 → 本日 commit 链。
