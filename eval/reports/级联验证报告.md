# 声纹三层级联验证报告（Day8 步9，大纲 8.4）

- 时间：2026-11-11；范围：声纹身份三层级联（单人间锁定 → 双人间声纹 → 失败兜底）
- 结论：**三层链路均已在 Day3/Day4 实测通过**（证据见各层）；Day8 步9 补充阈值扫描
  与真人基线复核，阈值维持 POC-04 真人基线 0.55（理由见《voiceprint_threshold.md》）。

## 第①层 单人间设备锁定（token 绑 room，设计目标 100%）

- 机制：设备 Token 注册时绑定房间（`app/models/device.py`），会话建立后按
  设备→房间→在住长者级联锁定 elder_id（`app/services/voice.py` 身份铁律，
  ADR-005）；elder_id 全程来自服务端 Runtime Context，不接受前端传参（AGENTS 禁区 8）。
- 实测（Day4，2026-11-06，`Day_plan/Day4_验收报告.md` 验收项 7）：
  TAB-A-101（A-1-101 单人间）→ 锁定王长寿，elder_id 级联正确；双人间设备不能
  自行录入声纹（ADR-005 拦截，走 `POST /api/v1/voice/enroll/admin` 管理员通道）。

## 第②层 双人间声纹确认（阈值 = 真人基线 0.55，扫描表供 Day10 复调）

- 机制：候选集合 = 同房间在住长者；active 声纹余弦最高分且
  ≥ `voiceprint_threshold`（`app/services/voice.py` 比对段）才放行并签发
  内存临时 Token（300s，不落库）。
- 真人实测（POC-04，Day3/Day4）：本人首句相似度 **0.5652 / 0.6786 / 0.6044 / 0.547**，
  均 ≥0.55 通过；他人（合成音）样本被拒；录入后免重连生效。
- Day8 步9 扫描（全合成口径，`voiceprint_threshold.md` 双表）：
  合成同人 0.8727–0.9420 / 他人 0.1583–0.6469，合成零误识区 ≥0.65；
  **与真人分布不可互移植**（合成同人天然偏高），故阈值不据此上调。

## 第③层 声纹失败主动确认兜底（「请问您是 XX 老人吗」→ 是/否）

- 机制：连续失败 `MAX_VERIFY_FAILURES=3` → WS 下发 `need_confirm` 事件 +
  候选长者名单，由长者/护理员在大屏主动选择（`app/services/voice.py`，ADR-008）；
  声纹不通过**不阻断对话**——进入通用模式（不带个人记忆），会话继续。
- 实测（POC-04）：无效语音/纯标点句不触发回复并如实提示"没听清"；
  声纹不通过进入通用模式，对话不中断；`tests/test_voiceprint_service.py` 28 例全绿。

## 局限与后续

1. 第②层阈值 0.55 基于 4 个真人首句样本 + 合成他人拒绝，样本量小（如实记录）；
   Day10 用真人双住户样本复调（扫描脚本 `python -m eval.voiceprint_threshold`
   支持换样本口径重跑出表）；
2. 声纹只作辅助身份信号（ADR-005/014），任何一层失败均降级、不阻塞服务；
3. 原始音频不落盘（TDD §4 禁区），本次扫描采用全合成口径（D9 用户裁决）。
